These shapes are accepted only through that dedicated import validator/commit. Preserve name, identity label, adapter, requested-model metadata, scope and original-channel data. No imported row can pass the live producer, claim, admission, queue eligibility or startup-resume gates.

Stored version provenance stays unchanged; reuse _validate_version unchanged and project import_source at read time. Local row shape and local audit validation remain unchanged. Imported rows are never pending/eligible or resumed/admitted, and set_attempt_state/commit_version refuse them. Imported-state without import_source refuses load.
- Packet bytes/original-channel/source-run/refs remain frozen; mutable outer channel alone is resolved/remapped. No reconstructing packets from local messages. No imported source reference is treated as a pointer authorizing local chat access.

## Whole-lineage commit and reports (P3)

Propose pure artifact_archive.py codecs/validation and dedicated ArtifactStore export-metadata/read-object/import-lineage methods; freeze exact payloads after this contract review. All immutable-object staging, packet/body validation and portable parsing happen outside the outer boundary; only current channel resolution/collision checks and one metadata-index commit occur inside it. Respect the existing max_channels and retired/reserved-name rules when creating import channels. Identical re-import is skipped/duplicate, not an error or another copy. Partial overlap skips the whole lineage and reports colliding id classes only. Existing partial import semantics continue, with per-artifact-section counts for created_lineages/versions/requests, duplicate/conflict/skipped lineages and exact reasons.
