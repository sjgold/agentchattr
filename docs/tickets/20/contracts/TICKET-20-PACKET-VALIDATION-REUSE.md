## Private mechanism and evidence type

Proposed implementation stays in artifact_store.py, with an ArtifactService entry-scope adapter. No new module, public argument, persisted field, owner attribute cache or on-disk object is added.

|Name/signature|Frozen behavior|
|---|---|
|`_packet_validation_invocation(owner)`|Private synchronous context manager creating one new `_PacketValidationInvocation` and setting a private ContextVar with a finally reset. It is called by a top-level selected service/MCP entry, never by a model or generic store read. A new top-level invocation always starts empty, even if another context value exists.|
|`_PacketValidationInvocation`|Private invocation-local record: owner object identity, resolved root/path identity captured from that owner, originating threading.get_ident(), fresh object() token, bounded evidence map. It is never assigned to the owner, queue, envelope, diagnostic intent, body or ledger. The context manager yields no evidence object to callers. Scope ends on success, exception, diagnostic failure or generator close; do not hand this synchronous context across tasks.|
|`_ValidatedPacketBytes`|Private frozen evidence: packet_id, exact raw immutable packet bytes and immutable canonical bytes of the FIRST successfully computed scope, created together by one full validation, plus owner/root/thread/token binding and raw length. It also carries immutable canonical audit_view_bytes for exactly packet.channel and packet.source_run, captured with that same scope/raw pair. No parsed packet, immutable tuple tree, deepcopy or cached audit/authority state. The invocation factory registers the issued object and exact raw/scope pair; mismatched/forged pairs fall back to full validation.|
|`_read_validated_packet_content(packet_id, raw, *, need_packet=True)`|Private store helper wrapping ONLY the current _packet content block, never _packet_scope. With no usable evidence, run the full existing content checks. On a hit require owner/root/thread/token, packet_id, raw length and EXACT raw equality plus the factory-issued matching scope/audit-view bytes. NO SHA-256 recomputation on a hit. json.loads(scope_bytes) returns a fresh computed scope and json.loads(audit_view_bytes) returns exactly channel/source_run for the every-read audit loop; json.loads(raw) returns a fresh packet only when need_packet is true. The helper returns (packet_or_none, scope, audit_view); outer _packet compares scope/view against current audits and retains its existing two-value return shape. No content walk/canonical compare on a hit. Any absent/forged/expired/mutated/mismatched evidence falls back to FULL validation. It never uses audit.scope as the computed side of the audit comparison.|
|`ArtifactService._packet_invocation(step)`|Private entry adapter: start a fresh store invocation scope around the complete synchronous selected operation, including its existing authority boundary. Only explicit internal nested helpers participate in that scope; unrelated public calls get a fresh scope. No caller parameter enables reuse. D4 later composes its diagnostic driver inside this scope; evidence contains no request-state/producer/queue authority.|

ContextVar alone does not establish thread ownership: compare threading.get_ident() on every evidence lookup, including when a copied context is deliberately entered on another thread. Another independent request on the same thread begins a fresh scope/token. Nested selected top-level calls isolate and restore their enclosing scope through ContextVar tokens rather than leaking evidence. A plain store method called after the service returns, in another thread, during startup scanning outside a selected service item or without the private adapter always fully validates.

The map is bounded to at most two entries and at most 2 * MAX_PACKET_BYTES raw packet bytes per invocation, plus the matching immutable scope encodings (roughly150KB scope plus2MiB raw per max-source entry in the measured shape). No cached parsed copies. The common chain uses one. A third distinct key or an oversize aggregate simply bypasses evidence storage and validates normally; do not evict/reassign evidence in a way that admits an unvalidated packet. No timing, error or acceptance depends on a cache entry being present. This memory-only implementation bound changes no packet, request, diagnostic or authoring admission limit.

The matching raw/scope/audit-view triple is stored only as immutable bytes. The audit view is a pure projection of the already validated packet, NOT current audit or authority state. The invocation registry retains the exact issued evidence identity and its original immutable pair/bindings; replacing a field or a registry entry without the issuance binding causes fallback. No unchecked scope-ingestion method exists. json.loads creates fresh computed-scope/audit-view objects on every hit and a fresh packet only when needed. Mutating either returned dict/list cannot change a later read or the immutable bytes. The store get_packet path returns that fresh parsed packet directly, without the old additional2MiB deepcopy on a hit; first/miss results are fresh parses too, so no owner-owned object is exposed. _packet may take private keyword _need_packet=False only at set_attempt_state:1316 and _commit_new:1363, whose existing callers discard the packet. It still validates fully on a miss and performs the current-audit loop using the two-field audit view, never packet=None indexing. These TWO STORE-LEVEL BARE CALLS discard the packet; service get_parent:296 and validate_enqueue:172 also discard their result but go through get_packet and keep its ordinary materialization. get_packet/_reserve_new/export keep the packet result. This flag changes materialization only, never validation/authority.

Root/path identity means the exact ArtifactStore object (two instances on the same directory are different), its resolved configured root and resolved authoring-index path captured at scope entry and compared on use; owned-path safety still executes at each real read. Detached means no mutable descendant is shared with evidence, the owner or a previous returned value. A selected public entry is an invocation adapter entry, whether called directly or from another public entry. Nested selected public entries ALWAYS get a fresh empty scope/token and restore the outer scope in finally, including on exception. Private locked helpers in the same public call join its scope. Evidence may survive a boundary release/reacquire only while that SAME invocation scope remains active; neither release nor re-entry makes it transferable to another invocation. recover_startup's calls to resume_request/admit_saved therefore each have fresh scopes, not one recovery-wide cache.

Error-only results are never cached. Failures caught by the existing _packet exception tuple record the same scoped object observation and raise the same ArtifactUnavailable. Uncaught errors preserve their existing behavior; in particular json.loads RecursionError escapes without a new object observation, as specified below. Successful hits still clear that same packet's prior observation at the existing point. A hit computes len(raw) and byte equality, not another hash; exact comparison of up to2MiB is the binding. The cached scope includes its existing packet SHA from the first full validation, used in the unchanged current-audit comparison. A same-size/mtime rewrite is caught by the fresh read, not a stat fingerprint. A packet file removed/replaced with a symlink or made unreadable between calls still executes the existing owned-path/read checks and refuses exactly as before.
