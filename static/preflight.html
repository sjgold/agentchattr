Configured agents

These checks only find executables. They do not start agents, install software, sign in, or send model requests.

Authentication and connection remain unknown until checked. Finding a command does not mean an agent is ready.

Your agent team

Save a team of API and interactive CLI seats. API launch starts a chat adapter; CLI launch opens the configured client in a Windows console or an owned tmux session. Sending instructions can consume provider usage.

Templates come from configured agents. CLI model and reasoning controls require an explicit argument contract. Manual model IDs are unverified. Saved edits apply on the next launch; a running seat requires an explicit restart.

CLI Launch writes MCP identity settings and keeps backups of intentional file edits. Native logins are reused. A client with a fixed shared settings file can run one owned seat at a time; conflicting seats require an isolated client profile.
