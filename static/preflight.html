API seats

Save provider and model choices, then launch the chat adapters. Launch does not call a model. Sending a chat message to a seat can consume provider usage.

Provider templates come from your configured API agents. Manual model IDs are unverified. Saved edits apply on the next launch; a running seat requires an explicit restart.
